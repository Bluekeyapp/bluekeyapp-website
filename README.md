# BlueKey company website

Independent company website at https://bluekeyapp.com/.

- Edit `index.html` to update company information, French text and English translations.
- Pushes to `main` deploy automatically through `.github/workflows/pages.yml`.
- This repository contains no SAB Security application code or database configuration.
- Legacy `/sabsecurity/` entry pages only redirect existing bookmarks to the separately deployed app at `https://sabsecurity.bluekeyapp.com/`.
- The `sw.js` files retire service workers from the previous shared deployment.
